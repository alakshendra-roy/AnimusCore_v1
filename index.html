Engine Architecture

You keep your existing Python orchestration and control plane. You replace only the hot path.

01

Lock-Free MPMC Ring

LockFreeRingBuffer<T> implements the Vyukov algorithm, cache-line-padded to eliminate false sharing. Verified correct under real 8-thread contention across 1.6M pushes.

02

Zero-Copy C-ABI Boundary

The Python SDK talks to the native engine through direct buffer pointers via ctypes — batched ingestion passes one raw byte buffer per batch, not one marshalled object per event.

03

Offline RSA-2048 Licensing

Hardware-bound, fail-closed verification with no phone-home and no license-server dependency. Gates only opt-in tuning features — core ingestion is never gated.
