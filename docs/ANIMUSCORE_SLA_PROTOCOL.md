# AnimusCore Partner Evaluation SLA & Integration Protocol (v1.0)

## 1. Operating Model & Communication Channel
- **100% Asynchronous & Written:** All technical reviews, profiling questions, hardware inquiries, and patch requests are handled exclusively via written communication.
- **Zero Real-Time Overhead:** Direct code reproduction and telemetry diffs replace live debugging sessions.

## 2. Issue Categorization & Response Targets
- **Tier A (Engine Blocker / Ring Contention Fault):** SLA turnaround within 24 hours.
- **Tier B (Bridge Interop / Telemetry Jitter):** SLA turnaround within 48 hours.
- **Tier C (Architecture Advisory & Custom Hardware Tuning):** Scoped asynchronously.
