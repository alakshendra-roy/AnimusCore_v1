# Animus Core — Gaming Infrastructure & Enterprise Security Pipeline

**Pitch angle:** a fourth, vertically distinct outbound motion — high-throughput C++ shops in game engine/multiplayer infrastructure and enterprise security/network intelligence, both of which run sub-microsecond, zero-allocation telemetry on a hot loop that cannot tolerate GC-style pauses (a server tick loop on one side, a kernel/daemon sensor loop on the other). Runs in parallel with the three existing motions ([`ICP_TARGET_LIST.md`](../operations_legal/ICP_TARGET_LIST.md), [`lead_pipeline.md`](lead_pipeline.md), [`indian_enterprise_pipeline.md`](indian_enterprise_pipeline.md)) — checked against all three trackers, zero overlap found as of 2026-09-24.

**Proof point (same soak, reframed per vertical):** 153-run, 62.1-minute unattended soak on i7-14650HX — 21.08ns median SPSC ingest (P90 24.39ns, P99 27.70ns), 30.59ns median tick-to-telemetry, 7.47M pushes/sec MPMC median under 8-producer contention, **0 bytes dynamically allocated** on the hot path across every run, **153/153 event sequences intact** across 21.3M+ total events, and the honest outlier — run #123 hit a single 30ms scheduler-preemption spike, reported as-is. Source: `artifacts/client_kit_soak_results/CLIENT_EVALUATION_SOAK_REPORT.md`. Do not blend with the Python-bridge motion's different benchmark configuration (p50 53.3ns / 47.3M msgs/sec).
