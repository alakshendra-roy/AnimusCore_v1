1Core Architectural Principles

Zero Dynamic Heap Allocation

0 malloc/free or new/delete calls post-init on the critical hot path.

Cacheline Isolation

Strict alignas(64) padding on slot, write_head, and read_tail indices — eliminates cross-core false sharing.

Invariant TSC Cycle Timing

Direct __rdtsc hardware serialization — bypasses standard clock / gettimeofday kernel context-switch overhead.

Zero-Copy Python Interop

~34.5ns nanobind ndarray bridge for real-time risk engines and quant research loops.

4Integration Footprint & Memory Topology

  • Header-only inclusion — single translation-unit friendly, no build-system integration required.
  • Dependency footprint — C++17 standard library only; no Boost / Abseil runtime dependency.
  • Ring Buffer Topology — cache-aligned slot layout with atomic sequence numbering.
