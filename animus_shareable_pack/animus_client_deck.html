What You're Actually Deploying

Built for Production, Not a Demo

Zero Allocations, Hot Path

No malloc/new on the produce/consume path — every slot is pre-allocated and alignas(64)-padded. Verified at 0 heap allocations across a 51.6-billion-event, 2h39m soak run under ASan/UBSan.
Lock-free MPMC ring buffer
4.55x measured A/B gain from cache-line padding

Standalone Evaluation Sandbox

Single-file, dependency-free harness in sandbox/bench_mpmc.cpp — checks cache-line alignment, zero-heap-allocation (enforced by overriding operator new/delete process-wide, hard-aborts on violation), and MPMC throughput. Run it on your own hardware rather than trusting a number in a slide deck.
Independently reproducible
Runs on your hardware, your data

Mission-Critical Integrity

Correctness is a hard-fail gate, not a hope: every pushed event must be drainable exactly once with an exact checksum match, or the binary exits with an error instead of reporting a result. Verified exact (51,623,591,903 = 51,623,591,903) across the full soak run.
